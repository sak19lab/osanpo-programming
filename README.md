# おさんぽプログラミング

年少〜年長さん向けの、はじめてのプログラミングあそび。
矢印カードを並べて ▶ を押すと、キャラクターがスタートからゴールまでおさんぽします。

## あそびかた

1. キャラクターをえらぶ（🤖🐱🐧🦖🐶）
2. ステージをえらぶ
3. 下の矢印カードをタップして並べる
4. ▶ スタート！

- 木にぶつかると、まちがえたカードが赤く光ります。下の矢印を押すと、そのカードだけ入れ替えられます
- 🧽 で 1 枚消す／🗑️ で全部消す
- 💡 ヒント：うすいキャラが正解の道をゆっくり歩いて、カードと同じ色の矢印を残します

## ステージ

| ワールド | 内容 |
|---|---|
| 1. はじめのいっぽ | → だけ |
| 2. まがりみち | ← ↑ ↓ → |
| 3. りんご ひろい | 🍎 を全部ひろってからゴール |
| 4. くりかえし | ×2・×3 カード |

## しくみ

- HTML ファイル 1 枚だけ。ライブラリなし、外部通信なし
- 進み具合はブラウザ（localStorage）に保存されます
- タブレットは横向きがおすすめ。ホーム画面に追加するとアプリのように使えます
